# bezmezh-admin-bot

Админ-бот сайта **БЕЗ МЕЖ** (http://bez-mezh.pp.ua/) — управление контентом через Telegram + уведомления о заявках.

## Что умеет

- 📥 Заявки с сайта (брони, обратный звонок, оплата, доставка, отзывы) — push админам, кнопка «Обработано»
- 🛣 Маршруты: добавление, цены, бейджи, скрытие
- 💶 Цены: авто-расчёт времени в пути (OSRM), курс €, надбавки, скидки, тарифная таблица
- ⭐ Отзывы, ❓ FAQ, 🏠 Главная, 📢 Объявление, 👤 Менеджеры, 📞 Контакты
- 👥 Администраторы: владелец + выдача/отзыв доступа через бота
- 🔴 Техработы, 📊 Журнал, 💾 Бэкап `site.json`

Переписки с посетителями нет — только заявки и уведомления. Посторонних бот молча игнорирует.

## Как устроено

- `bot.py` — весь бот, только стандартная библиотека Python (без зависимостей)
- Данные сайта живут в репозитории `Pashawilliams/bez-mezh-site` (`data/site.json`, GitHub Pages деплоит сам)
- Бот работает 24/7 через GitHub Actions: `.github/workflows/bot.yml` (самоперезапуск + сторож каждые 30 мин + breaker при падениях)

## Секреты репозитория

| Secret | Что это |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather |
| `ADMIN_ID` | Telegram ID владельца (`7906546417`) |
| `GH_PAT` | Personal Access Token с правом `contents: write` на `bez-mezh-site` |
| `STATE_SECRET` | (необязательно) пароль для шифрования `bot/state.json` |

## Запуск

Вручную: Actions → `Telegram admin bot` → `Run workflow`. Дальше бот перезапускает себя сам каждые ~5ч20м.
